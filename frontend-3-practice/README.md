# Мята — выбор даты и времени

Страница из `frontend-2-practice`, перенесённая на React и Vite.
Сохранены исходная вёрстка, адаптивные стили, шаг 4 из 6 и расписание слотов.

## Запуск

Нужен Node.js 22.12+ (или 20.19+).

```bash
cd frontend-3-practice
npm install
npm run dev
```

Откройте адрес, который напишет Vite (обычно http://localhost:3000).

```bash
npm run build   # сборка в dist/
npm run preview # просмотр сборки
npm run lint    # проверка ESLint
```

## Структура

- `src/App.jsx` — пять отдельных `useState`: просматриваемые месяц и год,
  выбранная дата, время и слоты; обработчики передаются через пропсы.
- `src/components/` — шапка, подвал, индикатор шагов, календарь
  (заголовок и сетка), слоты и нижняя панель. Один компонент — один файл.
- `src/utils/date.js` — чистые функции календаря, сравнения и форматирования дат.
- `src/data/slots.js` — девять слотов с теми же временами и алгоритмом занятости,
  что и в нативной версии. Это демонстрационные данные.
- `src/index.css` — базовый сброс; `src/styles/booking.css` — стили страницы.

Дни и слоты выводятся через `.map()` с `key`, клики обрабатываются через
`onClick`. Выбранная дата хранится целиком и не меняется при листании календаря.
Как и раньше, кнопка «Далее» показывает выбранные дату и время в уведомлении.

## Проверка поведения

1. При открытии выбран сегодняшний день, показаны его слоты, время ещё
   не выбрано, «Далее» недоступна.
2. Нажмите свободный слот: он выделяется, время появляется в нижней панели,
   «Далее» становится доступна. Занятые слоты выбрать нельзя.
3. Выберите другой день: выделение переносится, доступность слотов обновляется,
   выбранное время сбрасывается. Нижняя панель показывает день недели,
   число, месяц и год.
4. Перелистайте месяцы, включая переход декабрь → январь и обратно:
   заголовок и сетка обновляются, год меняется, ранее выбранная дата и время
   сохраняются. Выбор дня соседнего месяца открывает этот месяц.
5. Даты раньше сегодняшней приглушены и недоступны, в том числе в прошлых месяцах.
