# Выбор даты и времени

React-страница студии «Мята» из предыдущей практики, подключённая к
имитационному API через `fetchToday()` и `fetchSlots(date)` из `src/api.js`.

## Запуск

Требуется Node.js с npm. Из папки `frontend-4-practice` выполните:

```bash
npm install
npm run dev
```

Адрес приложения: `http://localhost:3000` (если порт занят, Vite укажет другой).
API запускается вместе с Vite, отдельный сервер не нужен.

## Поведение страницы

- При открытии загружается `/api/booking/today`, отображается «Загрузка…».
  Месяц календаря, выбранная дата и запрет прошедших дней определяются ответом сервера.
- После получения даты и при выборе нового дня загружается
  `/api/slots?day=&month=&year=`. Пока запрос выполняется, показано «Загрузка слотов…».
- Выбор другого дня сбрасывает время и старые слоты. Повторный клик по тому же дню
  и просмотр соседнего месяца не запускают лишний запрос.
- Для календаря и слотов предусмотрены отдельные сообщения об ошибках.
  При пустом списке слотов показано сообщение об отсутствии времени.
- При смене дня и размонтировании cleanup эффекта игнорирует устаревшие ответы,
  ошибки и завершение запросов. Дата в ответе дополнительно сверяется с запрошенной.
- Занятые слоты недоступны, кнопка «Далее» активируется после выбора свободного
  времени и показывает выбранную дату и время.

## Структура

- `src/App.jsx` — состояния, эффекты загрузки и обработчики выбора.
- `src/components/` — календарь, слоты, шапка, подвал и панель действий.
- `src/utils/date.js` — построение календаря, сравнение и форматирование дат.
- `src/styles/booking.css` — стили страницы из предыдущей практики.
- `src/api.js` — готовый клиент с проверкой HTTP-статуса.
- `server/database.js` — серверная дата и два набора слотов `{ time, available }`.
- `server/server.js` — готовый плагин Vite с задержкой ответа 500 мс.

Месяц в API нумеруется с нуля: январь — `0`, октябрь — `9`.
Дату и расписание можно менять в `server/database.js`.
